# FitLog — Gym Companion & Workout Library

FitLog is a dark, no-nonsense gym companion app built with Next.js and Tailwind CSS. Pick your lifts, lock them into today's plan, track metrics, and keep your gym work organized.

## Technologies Used
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (v4)
- **UI Components:** shadcn/ui
- **Icons & Assets:** Custom SVGs and Lucide React
- **Language:** TypeScript

## Key Features
1. **Interactive Library:** 12 compound and isolation lifts categorized across all major muscle groups.
2. **Today's Plan (5 Lifts Cap):** Add lifts to your daily routine with real-time total sets, minutes, and calories tracking.
3. **Sorting Engine:** Sort workout listings dynamically by Duration, Calories, Rating, or Name.
4. **Saved Lifts:** Bookmark favorite exercises to save for later sessions.
5. **Persisted State:** LocalStorage sync ensures workout plans survive browser refreshes.
